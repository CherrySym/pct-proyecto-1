# Proyecto 1 — Comandos básicos de Git

## Clonar un repo
```bash
git clone <url-del-repo>
```

## Traer cambios
```bash
git pull
```

## Guardar cambios
```bash
git add .
git commit -m "mensaje descriptivo"
git push
```

## Flujo diario
```bash
git pull
# ... editás código ...
git add .
git commit -m "mensaje descriptivo"
git push
```
